# 每日报告生成说明（已弃用 · 以云端部署说明为准）

> ⚠️ 本说明原用于「GUI 定时」方案，**已弃用**。当前采用「云端 GitHub Actions」方案，请以同目录下的 **云端部署说明.md** 为准。本文第四、五节的内容质量要求仍适用于云端生成的 prompt。

## 一、目标
每天早晨 **07:00 前**产出一份 HTML 日报，服务创业变现决策：
- 定位：社媒电商 AI 提效/自动化/无人化 + 传统行业 AI+智能体+自动化改造
- 目标：1~2 人团队做到**年利润 100~200 万元**
- 产出：易读排版 + 可展开详情 + 动效 + 免费语音播报按钮

## 二、触发与时间
- 定时任务每天 **06:45（北京时间）** 触发，确保 07:00 前整理完毕。
- 07:00 属空闲半价时段（工作日 9:00–12:00、14:00–18:00 之外，及周末/法定节假日全天）。
  日后接入 API Key 后，把「搜索 + 归纳」的 LLM 调用放在该窗口以降本。
- 当前阶段内容由**联网搜索 + 本人归纳**生成（无 API Key）。

## 三、执行步骤（每次触发必做）
1. **联网搜集**：用 web_search 跑 2~4 组查询，覆盖两个方向各 ≥2 个真实信号来源
   （新闻、平台政策、融资/招聘信号、行业报告、案例）。
2. **筛选归纳**：每个方向挑 3~5 条「真实需求明确、1~2 人能落地、可变现」的机会，
   优先近期政策/平台变动、供应链痛点、高频重复劳动。
3. **生成 HTML**：复制 `模板/report-template.html`，只替换顶部的 `REPORT` 对象：
   - `date` 用当天日期（yyyy-mm-dd）
   - `title` 用「概要」主题（如：`社媒电商AI与Agent市场机会`）
   - `opportunities` 数组逐条填写字段（见模板内注释）
4. **保存文件**：路径 `每日报告/yyyy-mm-dd-概要.html`（概要用简短主题，≤12 字）。
5. **呈现**：用 present 把当日报表呈现给用户。

## 四、内容质量要求
- 每条机会必须含：痛点/需求、需求信号（注明来源）、目标客户、产品形态、
  变现路径、收入模型、冷启动步骤、对标案例、风险。
- 优先级标注：高=近期需求强且易冷启动；中=需一定资源/关系；低=观察。
- 语言简洁、可执行，避免空话；每条一句话摘要要能直接打动客户。

## 五、命名示例
- `每日报告/2026-10-18-社媒电商AI与Agent机会.html`
- `每日报告/2026-10-19-AI无人直播与工厂Agent.html`

## 六、注意事项
- 报告末尾声明：内容仅供参考，不构成投资建议。
- 语音播报依赖浏览器 speechSynthesis（免费），Windows+Edge 音色最佳。
- 若当天无足够新信号，可复用历史高价值机会但需更新「需求信号」为最新来源。
