# 云端自动化部署说明（GitHub Actions · 每天 07:00 准时出报告）

本方案把「搜集 + 归纳 + 生成 HTML」搬到 GitHub 的 24 小时在线服务器上，
**不依赖本机、不依赖 GUI 是否开启、本机关机也照常运行**。每天早上北京时间 07:00 自动生成，
你开机后用浏览器打开即可查看。

## 一、你需要准备
1. 一个 GitHub 账号（免费注册 https://github.com）
2. DeepSeek API Key（在 https://platform.deepseek.com 的 API Keys 页面创建，形如 `sk-...`）

## 二、一次性配置（约 10 分钟）

### 第 1 步：新建仓库
GitHub 右上角「+」→ New repository → 仓库名随意（如 `ai-agent-report`）→ 选 **Private 私有**（推荐，避免你的 Key/内容公开）→ Create repository。

### 第 2 步：上传本目录这些文件到仓库根目录
把下面这些**原样上传**到仓库根目录（可在网页里「Add file → Upload files」拖拽上传，或克隆后用 git）：
- `.github/workflows/daily-report.yml`
- `generate_report.py`
- `模板/report-template.html`
- `每日报告/`（可为空文件夹，也可以先放一张示例报告）
- `index.html`（可为空文件；首次运行后会自动生成最新报告）

> 注意保持目录结构不变：`模板/report-template.html` 必须在 `模板/` 下，脚本按此路径读取模板。

### 第 3 步：配置密钥（Key 只放这里，绝不写进文件）
仓库 → **Settings → Secrets and variables → Actions → New repository secret**：
- Name 填：`DEEPSEEK_API_KEY`
- Secret 填：你的 `sk-...` Key
- 点 Add secret

### 第 4 步：手动触发一次，验证能跑通
仓库 → **Actions** 标签 → 左侧选 `Daily AI Agent Report` → 右侧 **Run workflow** → Run workflow。
约 1~2 分钟后刷新，看到绿色 ✓ 即成功；若失败，点进去看日志（常见原因：Key 填错、模板路径不对）。

### 第 5 步（可选但推荐）：开启 GitHub Pages，手机/浏览器直接看
仓库 → Settings → Pages → Source 选 **Deploy from a branch** → Branch 选 `main` + `/ (root)` → Save。
几分钟后访问：`https://你的用户名.github.io/仓库名/` 即是最新报告（带语音播报按钮，手机浏览器也能用）。
每天的历史报告在 `每日报告/` 目录里按日期归档。

## 三、定时说明
- 已内置每天 **北京时间 07:00**（GitHub cron = UTC 23:00）自动运行。
- GitHub 免费额度对本任务绰绰有余（每天一次、约 1 分钟）。
- GitHub 可能有几分钟调度延迟，属正常。

## 四、注意事项
1. **60 天无活动**：GitHub 对长期无「用户活动」的仓库可能暂停定时任务。若某天发现没生成，到 Actions 手动触发一次即恢复。
2. **成本**：每天约消耗 DeepSeek 几毛钱（deepseek-flash 归纳 + 搜索 API ¥5/千次）；07:00 属空闲半价时段（工作日 9:00–12:00、14:00–18:00 之外，及周末/法定节假日全天）。
3. **Key 安全**：Key 只放 GitHub Secrets，不要在 `generate_report.py` 或其他文件里明文写 Key，否则会泄露。
4. **语音播报**：HTML 内置浏览器语音合成，Windows + Edge 音色最佳；手机浏览器亦可用，需点击按钮允许语音。
